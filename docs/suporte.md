# Suporte seguro

Antes de pedir ajuda, execute:

```powershell
rtc-check --diagnostico
```

Copie somente essa saída redigida. Nunca anexe XML, certificado A1, senha, chave de
NF-e, licença ou dados de pagamento a uma issue pública.

Inclua versão do Windows/Python, versão do RTC Check, comando executado, código de
saída e se o erro ocorre na demonstração sintética. Para segurança, reporte
vulnerabilidades pelo canal privado descrito em `SECURITY.md`.
